## Usage

```swift
FLXButton("Show details", variant: .primary) {
    selectedDocument = Document(id: "Q3 roadmap.pdf")
}
.flxSheet(item: $selectedDocument) { document in
    Text(document.title)
        .padding()
}
```

`flxSheet` is a `View` modifier, like `.sheet`. It's always controlled: `item` comes from the presenting screen.

## Behavior

VoiceOver focus returns to the trigger when the sheet dismisses.

## Size

On macOS, a sheet sizes itself to its content, like a native sheet on the Mac, and `presentationDetents` has no effect. Give the content a size with `.frame(_:)`:

<ComponentPreviewCode
  code={`FLXButton("Show details", variant: .outline) {
    selectedDocument = Document(id: "Q3 roadmap.pdf")
}
.flxSheet(item: $selectedDocument) { document in
    Text(document.title)
        .frame(minWidth: 360, minHeight: 240)
}
`}

## Custom styling

`.sheet` has no style protocol, so there's no `FLXSheetStyle` or override.

## API Reference

### flxSheet

```swift
func flxSheet<Item: Identifiable, SheetContent: View>(
    item: Binding<Item?>,
    onDismiss: (() -> Void)? = nil,
    @ViewBuilder content: @escaping (Item) -> SheetContent
) -> some View
```

For more information about `.sheet`, see the [Apple documentation](https://developer.apple.com/documentation/swiftui/view/sheet(item:ondismiss:content:)).
