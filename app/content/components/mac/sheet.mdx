## Usage

The native `.sheet` already brings presentation, keyboard handling, accessibility, and its system appearance, so use it directly and put FLX components inside:

```swift
FLXButton("Show details", variant: .primary) {
    selectedDocument = Document(id: "Q3 roadmap.pdf")
}
.sheet(item: $selectedDocument) { document in
    Text(document.title)
        .frame(width: 320)
}
```

On macOS, a sheet sizes itself to its content and `presentationDetents` has no effect. Give the content a size with `.frame(_:)`.

## Background

The system draws the sheet's background. `.presentationBackground(_:)` replaces it, so leave it to the system unless you need a solid, themed sheet.

## VoiceOver focus

When a sheet dismisses, VoiceOver focus doesn't return to the control that opened it. Send it back with `@AccessibilityFocusState` and `onDismiss`:

```swift
@State private var selectedDocument: Document?
@AccessibilityFocusState private var isTriggerFocused: Bool

FLXButton("Show details", variant: .primary) {
    selectedDocument = Document(id: "Q3 roadmap.pdf")
}
.accessibilityFocused($isTriggerFocused)
.sheet(item: $selectedDocument, onDismiss: { isTriggerFocused = true }) { document in
    Text(document.title)
}
```

For more information about `.sheet`, see the [Apple documentation](https://developer.apple.com/documentation/swiftui/view/sheet(item:ondismiss:content:)).
