## Usage

`.searchable(text:prompt:)` adds the system search field, with its placement, keyboard handling, and clear button, so use it directly and filter your content with the text:

```swift
@State private var query = ""

NavigationStack {
    List(results) { message in
        MessageRow(message)
    }
    .navigationTitle("Inbox")
    .searchable(text: $query, prompt: "Search messages")
}
```

On macOS, the field sits at the trailing end of the window's toolbar. Filter the results as people type, and use the prompt to say what they can search for.

`.searchSuggestions` shows suggestions, such as recent searches, while the field is active. `.searchCompletion(_:)` fills the field when people pick one. On macOS they open in a menu below the field.

## Color

The field's focus ring and the selected scope follow the theme's `tint`, which `.flxTheme(_:)` applies at the root of your app.

For more information, see the Human Interface Guidelines for [search fields](https://developer.apple.com/design/human-interface-guidelines/search-fields) and the [Apple documentation](https://developer.apple.com/documentation/swiftui/adding-a-search-interface-to-your-app).
