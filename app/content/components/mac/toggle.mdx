## Usage

```swift
FLXToggle("Wi-Fi", isOn: $wifi)
```

`FLXToggle` is always controlled via `isOn`. On macOS it draws a checkbox, like SwiftUI's default `Toggle` on the Mac, with the label on the trailing side. The box follows `.controlSize(_:)`.

## Custom styling

`FLXToggleStyle` conforms to SwiftUI's native `ToggleStyle`. Override rendering for a subtree with any `ToggleStyle` via `.flxToggleStyle(_:)`:

<ComponentPreviewCode
  code={`VStack(alignment: .leading, spacing: FLXSpacing.sm) {
