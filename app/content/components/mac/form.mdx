## Usage

Inside a native `Form`, controls lay themselves out with their labels aligned. Use it directly.

```swift
Form {
    Toggle("Notifications", isOn: $notifications)
    Picker("Appearance", selection: $appearance) {
        ForEach(appearances, id: \.self) { Text($0) }
    }
}
.formStyle(.grouped)
```

Use a form for settings and data entry.

## Form or Form Field

Inside a form, use native controls. FLX fields draw their own box and label, so inside a form they repeat what the form already draws.

Use [Form Field](/docs/components/mac/form-field) and the other FLX fields in views outside a form.

## Theming

Apply the theme at the root of your app. `.flxTheme(_:)` also sets the theme's `tint`, so switches, selection marks and row buttons follow the theme in light and dark mode:

```swift
ContentView()
    .flxTheme(.default)
```

To use theme surfaces in a grouped form, hide the system background and set the row background:

```swift
Form { ... }
    .formStyle(.grouped)
    .scrollContentBackground(.hidden)
    .background(theme.colors.background)
    .listRowBackground(theme.colors.card)
```

For more information about `Form`, see the [Apple documentation](https://developer.apple.com/documentation/swiftui/form).
