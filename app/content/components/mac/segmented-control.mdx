## Usage

A `Picker` with the `.segmented` style already brings selection, keyboard and VoiceOver support, and its system appearance, so use it directly:

```swift
Picker("Range", selection: $range) {
    ForEach(ranges, id: \.self) { range in
        Text(range)
    }
}
.pickerStyle(.segmented)
```

macOS shows the title before the control, which tells people what it's for. To hide it, add `.labelsHidden()`. VoiceOver reads it either way.

Use a segmented control for a few short options, such as in a toolbar, an inspector, or a settings pane. For more options, use a `Picker` with the `.menu` style.

## Switching views

To switch the content in the main area of a window, use a [Tab View](/docs/components/mac/tab-view), not a segmented control. A segmented control can switch views in a toolbar or an inspector.

## Color

The selected segment uses the theme's `tint`, which `.flxTheme(_:)` applies. Without it, the control follows the app's `AccentColor`, so set that too, as in [Installation](/docs/installation#set-the-accent-color).

For more information, see the Human Interface Guidelines for [segmented controls](https://developer.apple.com/design/human-interface-guidelines/segmented-controls) and [tab views](https://developer.apple.com/design/human-interface-guidelines/tab-views).
