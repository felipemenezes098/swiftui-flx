## Liquid Glass

`FLXButton` is for the content layer: forms, cards, and lists. For controls that float above content, use the native `Button` with Apple's glass styles and bring the theme in through `.tint(_:)`. The system draws the glass and updates it with each OS release. Requires macOS 26.

### Glass and Glass Prominent

Use `.glass` for most floating controls and `.glassProminent` for the primary action, which fills with the tint.

<ComponentPreviewCode
  alt="Native glass buttons tinted with the theme"
  image={{ light: "/images/components/mac/button/button-glass.webp", dark: "/images/components/mac/button/button-glass-dark.webp" }}
  code={`@Environment(\\.flxTheme) private var theme

HStack(spacing: FLXSpacing.md) {
    Button("Filters", systemImage: "line.3.horizontal.decrease") {}
        .buttonStyle(.glass)
    Button("Add", systemImage: "plus") {}
        .buttonStyle(.glassProminent)
        .tint(theme.colors.primary)
}`}
/>

### Icon-only

Combine `.labelStyle(.iconOnly)` with `.buttonBorderShape(.circle)`.

<ComponentPreviewCode
  alt="Icon-only glass buttons"
  image={{ light: "/images/components/mac/button/button-glass-icons.webp", dark: "/images/components/mac/button/button-glass-icons-dark.webp" }}
  code={`HStack(spacing: FLXSpacing.md) {
    Button("Share", systemImage: "square.and.arrow.up") {}
        .buttonStyle(.glass)
    Button("Favorite", systemImage: "heart") {}
        .buttonStyle(.glass)
    Button("Add", systemImage: "plus") {}
        .buttonStyle(.glassProminent)
        .tint(theme.colors.primary)
}
.labelStyle(.iconOnly)
.buttonBorderShape(.circle)
.controlSize(.large)`}
/>

### Over media

Over photos and video, use `.glass(.clear)`. It's more transparent than `.glass`, so over bright media add a dark dimming layer to keep the symbols legible.

### Toolbar

In a toolbar, use a plain `Button` with no style: the system applies Liquid Glass to toolbar items, and items in the same `ToolbarItemGroup` share one background.

<ComponentPreviewCode
  alt="Toolbar buttons with system Liquid Glass"
  image={{ light: "/images/components/mac/button/button-glass-toolbar.webp", dark: "/images/components/mac/button/button-glass-toolbar-dark.webp" }}
  code={`@Environment(\\.flxTheme) private var theme

NavigationStack {
    VStack(spacing: FLXSpacing.md) {
        FLXAvatar(size: .large) {
            FLXAvatarFallback("FM")
            FLXAvatarImage(url: URL(string: "https://github.com/felipemenezes098.png"))
        }
        VStack(spacing: FLXSpacing.xs) {
            Text("Felipe Menezes")
                .flxFont(.title3, weight: .semibold)
            Text("Software Engineer")
                .flxFont(.callout)
                .foregroundStyle(theme.colors.mutedForeground)
        }
    }
    .frame(maxWidth: .infinity, maxHeight: .infinity)
    .navigationTitle("Profile")
    .toolbar {
        ToolbarItemGroup(placement: .primaryAction) {
            Button("Share", systemImage: "square.and.arrow.up") {}
            Button("More", systemImage: "ellipsis") {}
        }
    }
}`}
/>

Don't use Liquid Glass in the content layer, such as cards, lists, or forms. See Apple's [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) guidelines.

## As Link

To open a URL, use SwiftUI's native `Link` and apply `FLXButtonStyle`. `Link` keeps link semantics for VoiceOver and opens the URL itself, so don't use `FLXButton` with `openURL` in its action.

<ComponentPreviewCode
  alt="Link styled as a button"
  image={{ light: "/images/components/mac/button/button-as-link.webp", dark: "/images/components/mac/button/button-as-link-dark.webp" }}
  code={`Link("Open website", destination: url)
    .buttonStyle(FLXButtonStyle(variant: .primary))`}
/>

## Custom styling

`FLXButtonStyle` conforms to SwiftUI's native `ButtonStyle`. Override rendering for a subtree with any `ButtonStyle` via `.flxButtonStyle(_:)`:

<ComponentPreviewCode
  code={`
struct FLXPillButtonStyle: ButtonStyle {
    func makeBody(configuration: Configuration) -> some View {
        configuration.label
            .flxFont(.body, weight: .medium)
            .padding(.horizontal, FLXSpacing.xl)
            .padding(.vertical, FLXSpacing.md)
            .foregroundStyle(.white)
            .background(.blue.gradient)
            .clipShape(Capsule())
            .opacity(configuration.isPressed ? FLXOpacity.pressed : 1)
    }
}

HStack(spacing: FLXSpacing.md) {
    FLXButton("Pill", variant: .primary) {}
    FLXButton("Pill", variant: .primary) {}
        .flxButtonStyle(FLXPillButtonStyle())
}
`}
collapsible
  image={{ light: "/images/components/mac/button/button-custom.webp", dark: "/images/components/mac/button/button-custom-dark.webp" }}
/>

The override replaces `FLXButtonStyle` entirely, so `variant:` has no effect on buttons inside it. `role:` still reaches your style through `configuration.role`.

### Variants

| Case        | Description                           |
| ----------- | ------------------------------------- |
| `primary`   | Filled with `theme.colors.primary`.   |
| `outline`   | Transparent, bordered.                |
| `secondary` | Filled with `theme.colors.secondary`. |
| `ghost`     | Transparent, no border.               |
| `link`      | Text-only, styled like a hyperlink.   |

For more information about FLXButton props, see the [Apple documentation](https://developer.apple.com/documentation/swiftui/button).
