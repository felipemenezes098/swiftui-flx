## Usage

`DatePicker` already brings keyboard and VoiceOver support and the formats for every language and region, so use it directly:

```swift
DatePicker("Due date", selection: $dueDate, displayedComponents: .date)
```

macOS shows the title before a text field with a stepper. People type each part of the date or change it with the arrow keys. To hide the title, add `.labelsHidden()`. VoiceOver reads it either way.

### Range

Pass a range to `in:` to limit the dates people can pick.

```swift
DatePicker("Check-in", selection: $checkIn, in: Date.now..., displayedComponents: .date)
```

## Color

The system draws every date picker style in its own colors. None of them take the theme's `tint` or the app's `AccentColor`.

## Size

`.controlSize(_:)` changes the height of the field, from 20 points with `.small` to 26 with `.large`. The default, 22, is a little shorter than FLX's text fields.

For more information about date pickers, see the [Apple documentation](https://developer.apple.com/documentation/swiftui/datepicker).
