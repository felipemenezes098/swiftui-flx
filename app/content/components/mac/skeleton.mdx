## Usage

`FLXSkeleton` fills the space it's given, so set its size with `.frame` and its shape with `.clipShape`.

```swift
FLXSkeleton()
    .frame(width: 220, height: 16)
```

## Card

Compose skeletons in the same layout as the content they stand in for, so nothing moves when it loads.

## Redacted

To turn a view you already have into a placeholder, use SwiftUI's `.redacted(reason: .placeholder)`. It replaces text and images with blocks of the same size, so you don't build a second layout. Use `.unredacted()` on a part that should stay visible.

<ComponentPreviewCode
  alt="A profile row redacted as a placeholder"
  image={{ light: "/images/components/mac/skeleton/skeleton-redacted.webp", dark: "/images/components/mac/skeleton/skeleton-redacted-dark.webp" }}
  code={`HStack(spacing: FLXSpacing.md) {
    Image(systemName: "person.crop.circle.fill")
        .flxFont(.largeTitle)
    VStack(alignment: .leading) {
        Text("Olivia Martin")
            .flxFont(.headline)
        Text("olivia@example.com")
            .flxFont(.subheadline)
    }
}
.redacted(reason: .placeholder)
`}
/>

## Accessibility

`FLXSkeleton` is hidden from VoiceOver, and its pulse stops when Reduce Motion is on. Tell VoiceOver that the area is loading on the container:

```swift
VStack {
    FLXSkeleton()
        .frame(height: 120)
}
.accessibilityElement()
.accessibilityLabel("Loading")
```

## Custom styling

`FLXSkeletonStyle` is an FLX protocol. Override it for a subtree via `.flxSkeletonStyle(_:)`:

<ComponentPreviewCode
  alt="FLXSkeleton custom styling"
  image={{ light: "/images/components/mac/skeleton/skeleton-custom.webp", dark: "/images/components/mac/skeleton/skeleton-custom-dark.webp" }}
  code={`struct FLXStaticSkeletonStyle: FLXSkeletonStyle {
    func makeBody(configuration: Configuration) -> some View {
        Capsule()
            .fill(.quaternary)
    }
}

VStack(alignment: .leading, spacing: FLXSpacing.sm) {
    FLXSkeleton()
        .frame(width: 220, height: 16)
    FLXSkeleton()
        .frame(width: 160, height: 16)
}
.flxSkeletonStyle(FLXStaticSkeletonStyle())
`}
  collapsible
/>
