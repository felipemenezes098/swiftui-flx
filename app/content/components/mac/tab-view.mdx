## Usage

On macOS, a tab view groups related settings or details into panes, with the tabs on top. Mac apps use it in settings windows, inspectors, and dialogs, usually with a `Form` in each pane:

```swift
TabView {
    Tab("General", systemImage: "gearshape") {
        Form { ... }
    }
    Tab("Updates", systemImage: "arrow.down.circle") {
        Form { ... }
    }
}
.padding()
```

Keep the panes closely related, with up to six tabs, and keep the controls in each pane about that pane only. Leave a margin around the tab view, as in the example.

The main sections of a Mac app don't use a tab view. For those, use a sidebar with `NavigationSplitView`.

## Examples

### Settings window

Put a `TabView` in your app's `Settings` scene. In the settings window, macOS shows the tabs in the toolbar, with their symbols and titles.

```swift
struct MyApp: App {

            ContentView()

        Settings {
            SettingsView()

    }
}
```

## Color

The selected tab uses the theme's `tint`, which `.flxTheme(_:)` applies at the root of your app.

For more information, see the Human Interface Guidelines for [tab views](https://developer.apple.com/design/human-interface-guidelines/tab-views) and the [Apple documentation](https://developer.apple.com/documentation/swiftui/tabview).
