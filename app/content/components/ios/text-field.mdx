## Usage

```swift
FLXTextField("Email", text: $email)
```

## Custom styling

`TextFieldStyle` doesn't support custom conformances, so there's no `FLXTextFieldStyle` or override.

## API Reference

### FLXTextField

```swift
init(
    _ titleKey: LocalizedStringResource = "",
    text: Binding<String>
)

init<S: StringProtocol>(
    _ title: S,
    text: Binding<String>
)
```

For more information about FLXTextField props, see the [Apple documentation](https://developer.apple.com/documentation/swiftui/textfield).
