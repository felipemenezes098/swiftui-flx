## Usage

The native `NavigationStack` already brings the Liquid Glass navigation bar, the back button, the swipe back gesture, and accessibility, so use it directly:

```swift
NavigationStack {
    List(projects) { project in
        NavigationLink(value: project) {
            Label(project.name, systemImage: project.systemImage)
        }
    }
    .navigationTitle("Projects")
    .navigationDestination(for: Project.self) { project in
        ProjectView(project: project)
    }
}
```

`NavigationLink(value:)` pushes the screen that `.navigationDestination(for:)` returns for that value. Put the destination on the stack's content, outside the list rows.

`NavigationView` is deprecated. Use `NavigationStack` instead, or `NavigationSplitView` for columns.

Push a screen to show more about the item people chose. For a separate task, like creating an item, present a [Sheet](/docs/components/ios/sheet) instead. In a [Tab View](/docs/components/ios/tab-view), give each tab its own stack.

On iPad, prefer a tab view for your app's sections, and use `.tabViewStyle(.sidebarAdaptable)` when they need a sidebar. `NavigationSplitView` shows columns on iPad and collapses into a single stack on iPhone.

## Title

A large title helps people stay oriented. It moves into the bar as people scroll and comes back when they scroll to the top. To keep a screen's title small, use `.navigationBarTitleDisplayMode(.inline)`, as the pushed screens in the examples do.

Keep titles under 15 characters, so they leave room for the back button and toolbar items.

## Toolbar

To add actions to the navigation bar, use `.toolbar(content:)` with a plain `Button` or `Menu`, with no style. The system applies Liquid Glass, and items in the same `ToolbarItemGroup` share one background.

## Color

The title, the back button, and the chevrons of navigation links use system colors, which keep their contrast on Liquid Glass, so FLX leaves them as they are. Symbols in your rows, like a `Label`'s icon, use the theme's `tint`, which `.flxTheme(_:)` applies at the root of your app.

A plain list draws the system background. To show the theme's background instead, see [List](/docs/components/ios/list#theming).

For more information, see the Human Interface Guidelines for [toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars) and the [Apple documentation](https://developer.apple.com/documentation/swiftui/navigationstack).
