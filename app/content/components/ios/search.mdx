## Usage

`.searchable(text:prompt:)` adds the system search field, with its placement, Liquid Glass, keyboard, and clear button, so use it directly and filter your content with the text:

```swift
@State private var query = ""

NavigationStack {
    List(results) { message in
        MessageRow(message)
    }
    .navigationTitle("Inbox")
    .searchable(text: $query, prompt: "Search messages")
}
```

On iPhone, the field sits in the bottom toolbar, within easy reach. On iPad, it sits at the trailing end of the top toolbar. Filter the results as people type, and use the prompt to say what they can search for.

### Scopes

`.searchScopes` adds a scope bar to filter among clear categories. Start with the broadest scope, like All. By default, iOS shows scopes once people start typing. `activation: .onSearchPresentation` shows them as soon as search opens, as in the example.

## Color

The text cursor and the suggestion icons follow the theme's `tint`, which `.flxTheme(_:)` applies at the root of your app. The scope bar stays neutral, like a [Segmented Control](/docs/components/ios/segmented-control).

For more information, see the Human Interface Guidelines for [search fields](https://developer.apple.com/design/human-interface-guidelines/search-fields) and the [Apple documentation](https://developer.apple.com/documentation/swiftui/adding-a-search-interface-to-your-app).
