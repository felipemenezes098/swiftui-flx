## Usage

```swift
FLXPicker("Fruit", selection: $fruit) {
    Text("Apple").tag("Apple")
    Text("Banana").tag("Banana")
}
```

## Content

`FLXPicker` wraps the native `Picker` in `.menu` style. Populate it with any view tagged via `.tag(_:)`, typically a `ForEach`.

## Custom label triggers

Use the `content`/`label` initializer for a custom trigger like an avatar. No box decoration is applied:

<ComponentPreviewCode
  alt="FLXPicker custom label trigger"
  image={{ light: "/images/components/ios/picker/picker-trigger.webp", dark: "/images/components/ios/picker/picker-trigger-dark.webp" }}
  code={`FLXPicker(selection: $fruit) {
    Text("Apple").tag("Apple")
    Text("Banana").tag("Banana")
} label: {
    FLXAvatar(size: .small) {
        FLXAvatarFallback("A")
    }
}
`}
/>

## Custom styling

`PickerStyle` doesn't support custom conformances, so there's no `FLXPickerStyle` or override.

## API Reference

### FLXPicker

```swift
init(
    selection: Binding<SelectionValue>,
    @ViewBuilder content: @escaping () -> Content,
    @ViewBuilder label: @escaping () -> Label
)

init(
    _ titleKey: LocalizedStringKey = "",
    selection: Binding<SelectionValue>,
    @ViewBuilder content: @escaping () -> Content
)

init(
    _ titleResource: LocalizedStringResource,
    selection: Binding<SelectionValue>,
    @ViewBuilder content: @escaping () -> Content
)

init<S: StringProtocol>(
    _ title: S,
    selection: Binding<SelectionValue>,
    @ViewBuilder content: @escaping () -> Content
)
```

For more information about FLXPicker props, see the [Apple documentation](https://developer.apple.com/documentation/swiftui/picker).
