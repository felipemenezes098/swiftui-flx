## Usage

Inside a native `Form`, each control becomes a settings row, with the label on the leading side and the value on the trailing side. Use it directly.

```swift
Form {
    Section("Preferences") {
        Toggle("Notifications", isOn: $notifications)
        Picker("Appearance", selection: $appearance) {
            ForEach(appearances, id: \.self) { Text($0) }
        }
    }
}
```

Use a form for settings and data entry. To show a collection of items, use a [List](/docs/components/ios/list).

## Form or Form Field

Inside a form, use native controls. FLX fields draw their own box, so inside a form row they show a box inside a box.

Use [Form Field](/docs/components/ios/form-field) and the other FLX fields on screens outside a form, such as sign-in or onboarding.

## Theming

Apply the theme at the root of your app. `.flxTheme(_:)` also sets the theme's `tint`, so switches, selection marks, swipe actions, and row buttons follow the theme in light and dark mode:

```swift
ContentView()
    .flxTheme(.default)
```

To use theme surfaces, hide the system background and set the row background and separator color. Rows stand apart from the background only by contrast, so pick colors that stay apart:

```swift
Form { ... }
    .scrollContentBackground(.hidden)
    .background(theme.colors.background)
    .listRowBackground(theme.colors.card)
    .listRowSeparatorTint(theme.colors.border)
```

For more information about `Form`, see the [Apple documentation](https://developer.apple.com/documentation/swiftui/form).
