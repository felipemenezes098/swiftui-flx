## Usage

Apple has no toast API, so `.flxToast` follows the shape of `.alert` and `.sheet`: a binding shows it, and the toast sets it back to `false` when it goes away.

```swift
@State private var isSaved = false

FLXButton("Save changes", variant: .primary) {
    isSaved = true
}
.flxToast("Changes saved", isPresented: $isSaved)
```

Use a toast for feedback about something the person just did. Errors and anything they must read belong in an [alert](/docs/components/ios/alert).

## Icon and message

`systemImage` adds an SF Symbol in the tint color, and `message` adds a line under the title.

## Actions

Add actions with a trailing closure. A toast with actions doesn't time out: it stays until the person taps an action or the close button that FLX adds next to them. Every action closes the toast, like an alert's buttons.

<ComponentPreviewCode
  alt="FLXToast with an Undo action and a close button"
  image={{ light: "/images/components/ios/toast/toast-actions.webp", dark: "/images/components/ios/toast/toast-actions-dark.webp" }}
  code={`.flxToast(
    "Project archived",
    systemImage: "archivebox",
    isPresented: $isArchived,
    message: "Moved to Archive."
) {
    Button("Undo") {
        restore()
    }
}
`}
/>

Don't give an action its own `.buttonStyle(_:)`. The toast closes through its own button style, and the innermost style wins, so that button would stop closing the toast.

## Item

Use `isPresented:` for one toast on the screen, and `item:` for several. The toast reads its title from an `Identifiable` value. A value with a new `id` replaces the toast; the same `id` with new data updates it in place without restarting its timer.

<ComponentPreviewCode
  alt="FLXToast presented from an item with the title Archived 3 messages"
  image={{ light: "/images/components/ios/toast/toast-item.webp", dark: "/images/components/ios/toast/toast-item-dark.webp" }}
  code={`struct Archive: Identifiable {
    let id = UUID()
    let count: Int
}

@State private var archive: Archive?

FLXButton("Archive 3 messages", variant: .secondary) {
    archive = Archive(count: 3)
}
.flxToast(item: $archive, systemImage: "archivebox") { "Archived \\($0.count) messages" }
`}
  collapsible
/>

`systemImage`, `edge`, and `duration` apply to the whole modifier. When different values need a different icon, give each its own `.flxToast`.

## Duration

A toast without actions closes after 4 seconds. Give longer text more time with `duration:`, so people can finish reading it.

<ComponentPreviewCode
  alt="FLXToast with a two-line message"
  image={{ light: "/images/components/ios/toast/toast-duration.webp", dark: "/images/components/ios/toast/toast-duration-dark.webp" }}
  code={`.flxToast(
    "Export finished",
    systemImage: "square.and.arrow.up",
    isPresented: $isExported,
    message: "Q3 roadmap.pdf and 12 other files are ready in the Files app.",
    duration: .seconds(8)
)
`}
/>

The timer pauses while VoiceOver is on, while the pointer hovers over the toast, while it's being dragged, and while the app is in the background.

## Placement

Attach toasts to the root container, such as a `NavigationStack` or `TabView`. Attached to the content inside it, the toast sits below the navigation bar.

<ComponentPreviewCode
  alt="FLXToast over a navigation bar"
  image={{ light: "/images/components/ios/toast/toast-placement.webp", dark: "/images/components/ios/toast/toast-placement-dark.webp" }}
  code={`NavigationStack {
    SettingsView()
        .navigationTitle("Settings")
}
.flxToast("Changes saved", systemImage: "checkmark.circle.fill", isPresented: $isSaved)
`}
/>

Only one toast shows at a time. The outermost `.flxToast` owns the spot, and every toast inside it, including those on pushed screens, goes there: the newest replaces the one on screen, whose binding goes back to `false` or `nil`. No setup is needed.

A sheet is presented apart from the screen behind it, so a sheet that shows toasts needs its own `.flxToast` on its root view:

```swift
.sheet(isPresented: $isEditing) {
    NavigationStack {
        EditView()
    }
    .flxToast("Draft saved", isPresented: $isDraftSaved)
}
```

## Text and translation

The title is a `LocalizedStringResource`, so a literal is translated and extracted to your String Catalog. Pass a `String` variable to show it as is, such as a file name.

The message is always a `LocalizedStringResource`. Put runtime values in through interpolation, which keeps the rest of the sentence translated:

<ComponentPreviewCode
  alt="FLXToast with a file name as the title and a translated message"
  image={{ light: "/images/components/ios/toast/toast-localization.webp", dark: "/images/components/ios/toast/toast-localization-dark.webp" }}
  code={`.flxToast(
    fileName,
    systemImage: "folder",
    isPresented: $isMoved,
    message: "Moved to \\(folder)."
)
`}
/>

For a message that comes entirely from runtime, interpolate it on its own: `message: "\(detail)"`. Passing a `String` directly doesn't compile, which keeps literals from silently losing their translation.

## Accessibility

- VoiceOver announces the title and message when the toast appears (iOS 17 and later), and the toast never times out while VoiceOver is on.
- Swiping toward the edge isn't the only way to close: a toast with actions has a close button, and VoiceOver's escape gesture closes any toast.
- With Reduce Motion on, the toast fades instead of sliding.

Before iOS 26, the close button's label is `Close`, translated only when your String Catalog (`Localizable.xcstrings`) has that key. From iOS 26, the system close button brings its own translation.

```json
"Close" : {
  "localizations" : {
    "pt-BR" : { "stringUnit" : { "state" : "translated", "value" : "Fechar" } }
  }
}
```

## Custom styling

`FLXToastStyle` is an FLX protocol. Override it for a subtree via `.flxToastStyle(_:)`. The surface uses Liquid Glass on iOS 26 and later and the regular material before it; a custom style draws its own.

<ComponentPreviewCode
  alt="FLXToast with a solid capsule style"
  image={{ light: "/images/components/ios/toast/toast-custom.webp", dark: "/images/components/ios/toast/toast-custom-dark.webp" }}
  code={`struct FLXSolidToastStyle: FLXToastStyle {
    func makeBody(configuration: Configuration) -> some View {
        FLXSolidToastStyleBody(configuration: configuration)
    }
}

struct FLXSolidToastStyleBody: View {
    @Environment(\\.flxTheme) private var theme

    let configuration: FLXToastStyleConfiguration

    var body: some View {
        HStack(spacing: FLXSpacing.md) {
            if let systemImage = configuration.systemImage {
                Image(systemName: systemImage)
                    .accessibilityHidden(true)
            }
            VStack(alignment: .leading) {
                configuration.title
                    .flxFont(.subheadline, weight: .semibold)
                if let message = configuration.message {
                    message
                        .flxFont(.footnote)
                }
            }
            if let actions = configuration.actions {
                Spacer(minLength: 0)
                actions
                    .buttonStyle(.borderless)
                    .flxFont(.subheadline, weight: .semibold)
            }
        }
        .foregroundStyle(theme.colors.primaryForeground)
        .padding(.horizontal, FLXSpacing.lg)
        .padding(.vertical, FLXSpacing.md)
        .background(theme.colors.primary, in: Capsule())
        .accessibilityElement(children: .contain)
    }
}

ContentView()
    .flxToastStyle(FLXSolidToastStyle())
`}
  collapsible
/>

`configuration.actions` already includes the close button and closes the toast when tapped, so the style only places it. It is `nil` for a toast without actions.

## API Reference

### flxToast(_:isPresented:)

```swift
func flxToast(
    _ titleResource: LocalizedStringResource,
    systemImage: String? = nil,
    isPresented: Binding<Bool>,
    message: LocalizedStringResource? = nil,
    edge: VerticalEdge = .top,
    duration: Duration = .seconds(4)
) -> some View

func flxToast<A: View>(
    _ titleResource: LocalizedStringResource,
    systemImage: String? = nil,
    isPresented: Binding<Bool>,
    message: LocalizedStringResource? = nil,
    edge: VerticalEdge = .top,
    @ViewBuilder actions: () -> A
) -> some View
```

Both also take a `StringProtocol` title, shown as is.

### flxToast(item:)

```swift
func flxToast<T: Identifiable>(
    item: Binding<T?>,
    systemImage: String? = nil,
    edge: VerticalEdge = .top,
    duration: Duration = .seconds(4),
    title: (T) -> LocalizedStringResource,
    message: ((T) -> LocalizedStringResource)? = nil
) -> some View

func flxToast<T: Identifiable, A: View>(
    item: Binding<T?>,
    systemImage: String? = nil,
    edge: VerticalEdge = .top,
    title: (T) -> LocalizedStringResource,
    message: ((T) -> LocalizedStringResource)? = nil,
    @ViewBuilder actions: (T) -> A
) -> some View
```

The `title` closure can also return a `StringProtocol` value.

### FLXToastStyleConfiguration

| Property | Type | Description |
| --- | --- | --- |
| `title` | `Text` | The toast's title. |
| `message` | `Text?` | The line under the title. |
| `systemImage` | `String?` | The SF Symbol name. |
| `actions` | `Actions?` | The actions and the close button, or `nil` for a toast that times out. |
