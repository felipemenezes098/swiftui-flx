## Usage

The native `List` already brings rows, separators, selection, swipe actions, and accessibility. Use it directly and put FLX components inside the rows.

```swift
List(contacts) { contact in
    HStack(spacing: FLXSpacing.md) {
        FLXAvatar(size: .small) {
            FLXAvatarFallback(contact.initials)
        }
        Text(contact.name)
    }
}
```

Use a list to show a collection of items, such as messages, contacts, or tasks. For settings and data entry, use a [Form](/docs/components/ios/form).

## Theming

Apply the theme at the root of your app. `.flxTheme(_:)` also sets the theme's `tint`, so switches, selection marks, swipe actions, and row buttons follow the theme in light and dark mode:

```swift
ContentView()
    .flxTheme(.default)
```

To use theme surfaces, hide the system background and set the row background and separator color. Rows stand apart from the background only by contrast, so pick colors that stay apart:

```swift
List { ... }
    .scrollContentBackground(.hidden)
    .background(theme.colors.background)
    .listRowBackground(theme.colors.card)
    .listRowSeparatorTint(theme.colors.border)
```

For more information about `List`, see the [Apple documentation](https://developer.apple.com/documentation/swiftui/list).
