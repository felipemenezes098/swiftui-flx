## Usage

The native `TabView` already brings the Liquid Glass tab bar, its layout on iPhone and iPad, and accessibility, so use it directly and put your screens inside:

```swift
TabView {
    Tab("Inbox", systemImage: "tray.fill") {
        NavigationStack {
            InboxView()
        }
    }
    Tab("Settings", systemImage: "gearshape.fill") {
        NavigationStack {
            SettingsView()
        }
    }
}
```

Give each tab its own `NavigationStack`, so each section keeps its place when people switch tabs.

Use tabs to move between the main sections of your app, not to perform actions. For actions on the current screen, use a toolbar. Give every tab a short label and an SF Symbol, preferably a filled one.

## Minimize on scroll

On iOS 26 and later, `.tabBarMinimizeBehavior(.onScrollDown)` shrinks the tab bar while people scroll down, so content gets more room:

```swift
TabView { ... }
    .tabBarMinimizeBehavior(.onScrollDown)
```

## iPad

On iPad, the tab bar appears near the top of the screen. `.tabViewStyle(.sidebarAdaptable)` adds a button that turns it into a sidebar, for apps with more sections.

## Color

The selected tab uses the theme's `tint`, which `.flxTheme(_:)` applies at the root of your app.

## Tab View or Segmented Control

Use a tab view for the main sections of your app. To switch between closely related views inside one screen, use a [Segmented Control](/docs/components/ios/segmented-control).

For more information, see the Human Interface Guidelines for [tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars) and the [Apple documentation](https://developer.apple.com/documentation/swiftui/tabview).
