**New [One-Time Code Field](/docs/components/ios/one-time-code-field) component for iOS.**

A verification code input drawn as boxes over one hidden system text field: `FLXOneTimeCodeField("Verification code", text: $code)`. Because the text field is real, codes from Messages, Mail, and password apps show up above the keyboard, and paste works as expected.

Split the boxes into groups with `FLXDefaultOneTimeCodeFieldStyle(groupSize: 3)`, or draw your own with `.flxOneTimeCodeFieldStyle(_:)`.

No existing component changed.
