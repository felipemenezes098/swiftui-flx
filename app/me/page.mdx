# Me

I built swiftui-flx to scale how I build with SwiftUI, and to keep learning while doing it.

Every app starts the same way. Buttons, fields, sheets, spacing, colors. Rebuilding them each time is slow, and small differences pile up until nothing feels consistent.

With one place for components, tokens and themes, consistency holds across projects and I move fast.

It also gives AI agents the right premises. Good docs and a clear taste mean the agent follows the same rules I do, instead of inventing a new UI language on every screen.

It's inspired by [shadcn/ui](https://ui.shadcn.com), which I use every day. You get the source. You own it, style it, extend it, ship it. I also maintain an open source project around shadcn, adapted to how I work: [ui.flexnative.com](https://ui.flexnative.com).

swiftui-flx is the same idea, native.
